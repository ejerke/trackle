# 0001. Record architecture decisions

- Status: Accepted
- Date: 2026-11-10

## Context

This is a learning project. Code shows *what* was built, but not *why* or what
was rejected. That reasoning is the most valuable thing to remember later.

## Decision

Record significant decisions as numbered, short Markdown ADRs in `docs/adr/`,
using the template in `0000-template.md`.

## Consequences

- Each decision has a place to link to from code review, docs and commits.
- Changing our mind is cheap and visible: write a new ADR that supersedes the old.
- Small, reversible choices do not need an ADR.
